This project converts a Tuya‑based smart plug into a fully local, privacy‑friendly device powered by ESPHome and an ESP‑02S (ESP8285) module.
It supports relay control, button input, status LED, and BL0937 power monitoring, all integrated with Home Assistant.<img width="4000" height="2252" alt="20260505_203726" src="https://github.com/user-attachments/assets/0007118d-05b3-4905-a353-3be6bcd2a330" />


| Function | GPIO | Notes |
| --- | --- | --- |
| Relay | **GPIO14** | Controls the main AC relay |
| Button | **GPIO3 (RX)** | Physical button on the case |
| Status LED | **GPIO13** | Red LED indicator |
| BL0937 SEL | **GPIO12** | Selects voltage/current mode |
| BL0937 CF | **GPIO4** | Power pulse output |
| BL0937 CF1 | **GPIO5** | Voltage/current pulse output |
